# Hello Kitty Desktop Pet

A Vue + Vite + Electron desktop pet project with local animation assets, sound effects, and a packaged Windows build workflow.

## Features

- Animated Hello Kitty desktop companion.
- Electron desktop shell with Vite-powered renderer.
- Local interaction sounds.
- `.env.example` for optional Qwen API key configuration.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build:renderer
npm run build
```

## Environment

Copy `.env.example` to `.env` only for local development.

```env
QWEN_API_KEY=YOUR_API_KEY_HERE
```
